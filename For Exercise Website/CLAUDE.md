# Grade calculator

## Stack
- Plain HTML, CSS and JavaScript only. No frameworks, no libraries, no CDN links.
- Files: index.html, css/style.css, js/grades.js (calculations only), js/app.js (page and buttons only).
- No inline styles and no inline onclick attributes.

## School rules (DepEd)
- Grades are 0 to 100. The final grade is the average of the four quarters, rounded to 2 decimals.
- 75 and above is PASSED, below 75 is FAILED.
- If any quarter is empty, the remark is INC and no final grade is shown.

## How to work with me
- I am a teacher learning web development. Before writing code, show me a short plan and wait for my OK.
- After writing code, explain each file in 2 or 3 plain sentences.
- Write comments a Grade 10 student could understand.
